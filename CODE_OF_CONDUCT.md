# Código de Conduta

## Nosso compromisso

Queremos que a comunidade do FreshBeat seja aberta, acolhedora e segura para todo mundo, independentemente de idade, corpo, deficiência, etnia, identidade e expressão de gênero, nível de experiência, nacionalidade, aparência, raça, religião ou orientação sexual.

## Comportamento esperado

- Seja gentil e paciente, especialmente com quem está começando
- Aceite críticas construtivas de bom grado
- Foque no que é melhor para a comunidade e para o projeto

## Comportamento inaceitável

- Assédio, insultos ou comentários depreciativos
- Publicação de informações privadas de terceiros
- Qualquer conduta que seria inadequada em um ambiente profissional

## Aplicação

Casos de comportamento abusivo podem ser reportados ao mantenedor do projeto via GitHub ([@JPSAUD501](https://github.com/JPSAUD501)). Todas as reclamações serão revisadas e investigadas com confidencialidade.

Este código de conduta é adaptado do [Contributor Covenant](https://www.contributor-covenant.org/), versão 2.1.
